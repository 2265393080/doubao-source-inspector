# 豆包联网来源分析器

Chrome Manifest V3 扩展，用于直接标注豆包网页对话中的联网搜索来源。

## 页面内显示

安装后无需点击插件，每次打开豆包页面都会自动生效：

- 在每条联网搜索结果的序号和标题之间插入来源标签，例如 `1.  搜狐  文章标题`。
- 按 `data-tool-call-item-id` 中的 `…-result-N` 自动识别同一批搜索结果。
- 在每批结果末尾显示来源汇总，例如：`来源汇总  抖音 8个  搜狐 2个  共10条`。
- 对豆包流式生成和后续动态加载的结果自动更新。
- 已内置搜狐、抖音、今日头条、网易、凤凰网、法律快车、知乎、百度、腾讯等常见来源名称映射；未知网站显示简化域名。

## 弹窗分析

点击浏览器工具栏中的插件图标，仍可：

- 从 `window._ROUTER_DATA` 或页面 SSR 脚本中提取搜索结果卡片。
- 查看网站、域名、标题、链接、搜索批次 `search_id`、原始排名和发布时间。
- 将“搜索引用网站”与“浏览器实际请求域名”分开显示。
- 筛选、复制以及导出 CSV/JSON。

## 安装或升级

1. 解压插件 ZIP。
2. Chrome 地址栏打开 `chrome://extensions/`。
3. 开启右上角“开发者模式”。
4. 首次安装：点击“加载已解压的扩展程序”，选择 `doubao-source-inspector` 文件夹。
5. 已安装旧版：用新文件覆盖旧目录后，在扩展卡片上点击刷新按钮。
6. 刷新已打开的豆包页面。

## 页面匹配逻辑

插件识别以下元素：

```html
<a
  data-thinking-box-tool-call="true"
  data-tool-call-item-id="...-result-0"
  href="https://外部网站/..."
>
```

来源名称由链接域名推断。汇总以 `-result-` 前面的 ID 作为分组键，因此不同联网搜索批次不会混合统计。

## 隐私

所有分析和页面注入都在浏览器本地完成，不上传页面内容。
